# 水声线谱评价

回答“已有线谱检测结果表现怎样、证据能支持什么结论”。检测模块回答“按什么规则找出候选”。两者共享来源与证据，不共享隐式执行权限。优先使用用户的语言报告。

## V1 能力

本 Skill 已实现评价运行时 1.0.0，并保留 EvaluationRequest、TruthCoverage、EvaluationResult 0.1.0 严格契约。可以：

- 跨文档核对 DetectionResult、实际配置、候选 product、包含零候选帧的 ledger、文件摘要和 run/task/signal 身份；
- 无真值时计算候选数、帧均候选数、有候选帧占比、门限余量和背景对比；
- 完整标注时按显式时频门宽做一对一匹配，计算 recall、precision、F1、误报数与频率误差；
- 部分正标注时只计算已匹配项频率误差，不把未标注候选当 FP；
- 可信背景时计算候选层或 CFAR 单元层的误报计数、帧/时长/背景区域比例；
- 生成严格 EvaluationResult、指标表、匹配审计表、报告与摘要清单，不覆盖旧结果。

算法、输入门禁、命令及输出包完整规则见 [评价执行器 V1](references/runtime-v1.md)。

## 先判证据，再选指标

- 有真值：先核对来源、可靠性、覆盖、标注粒度和正负类语义。“预计频率”不自动成为真值。
- 无真值：可精确报告候选与已有判据的描述统计，但候选数不是误报数，不声称实测检出率或准确率。
- 局部标注：只支持其明确覆盖的结论；可信背景是有依据的 H0 证据，不是“没标注”或“看起来安静”。
- 仅有图片：通常只做定性或有限半定量审查，不伪造精确数值。

设计、计算或解释指标前，完整阅读 [证据与指标规则](references/evidence-and-metrics.md)。接收结果、标签、波束来源或交付时，完整阅读 [评价交接与协作](references/evaluation-handoff.md)。编写 JSON 或检查契约时，完整阅读 [评价字段与检查](references/schema-validation.md)。

## 自主评价策略

用户要求评价已有检测结果即授权执行证据允许的评价，不再逐项确认指标、图表、输出目录或执行步骤。自动选择模式和指标：无真值时计算全部核心候选描述统计；局部正标注时只计算其支持的匹配与误差；完整正负覆盖时增加 recall、precision、F1 和误报指标；可信背景只计算其覆盖内的背景误报指标。

- 缺少真值、可信背景、基线或验收阈值只限制相应结论，不阻断其余指标，也不要求用户补造这些证据。
- 匹配门宽优先使用标签不确定度或检测分辨率；没有标签不确定度时采用不小于一个频率栅格的基线门宽，并明确这是分析设置。时间规则、分配和平局规则使用运行时的确定性基线；必要时可做小范围敏感性检查，但不据此冒充真实准确率。
- 用户未指定目标任务时，若包中只有一个已完成任务就直接选；多个同等合理任务才合并询问。多个可比算法结果可自动比较，不可比时分别报告。
- confirmation 如实记录当前评价请求与项目级自主决策授权，不伪称用户逐项指定参数。preflight 通过后直接 execute。
- 真正需要输入时，先完成其余可计算项，再把全部当前阻断项、推荐选择和影响放在一个“需要你确认”清单中。

## 工作流程

1. 解析要评价的已有 result/run/task/signal/波束、时间、频带和问题。唯一完成对象直接选择；多个同等合理对象不按“最好结果”擅自取一个，而是合并询问或分别评价。
2. 进行只读契约检查和跨文档预检；区分成功零候选、未运行、失败、截断与文件不可用。
3. 按真值/背景覆盖列出每项指标的可计算性。只阻断依赖缺失证据的指标，其他已明确工作可继续。
4. 需要匹配时，按真值不确定度、检测栅格和运行时确定性规则解析频率门宽、时间规则、分配方法、平局与重复候选规则，并记录依据；旧实验参数只有与当前来源绑定时才能复用。
5. 先运行 `--preflight-only`，预检通过后按原请求执行评价。需要补谱、重新检测、改门限或波束补算时，列为独立追加建议，不藏在“评价”中。
6. 报告指标定义、分子/分母、单位、实际覆盖、证据来源和局限。计算完成、证据充分、产物保存和工程验收是不同状态。

## 必须保留的边界

- 未知数据事实不得伪造；可逆评价设置可按上方规则推导。不静默转置、补标注、插值、重采样、补掩码、拼接缺口或改标定。
- 真线谱存在与“属于哪个目标”分开。其他声源的真窄带线不自动是通用检测的误报。
- 门限模型、标定集观测和独立验证集观测分开；用于定门限的数据不得冒充独立效果验证。
- CBF/MVDR 或 CA/OS 的同源一致性可作联合证据，不是独立真值、候选正确概率或目标归属。
- 原数据、检测结果和上游完成包只读；评价包另存，并拒绝覆盖已有输出目录。
- 未请求、不适用、证据不足、待确认、未定义、计算失败和未实现要区分；不可算值为 null 并写原因，不填 0。

## 与其他 Skill 的边界

- `underwater-line-spectrum-detection`：生成候选、谱、门限、ledger 和检测包。评价不调用其重新检测。
- `underwater-beamforming`：生成指定波束及空间证据。评价只保留和核对来源。
- `underwater-beamforming-evaluation`：评价 DOA、空间分辨率、主瓣/旁瓣或波束性能。不并入线谱检测性能。
- 频率轨迹跟踪、谐波结构融合、声源关联和目标识别属于后续独立模块，不因评价需求自动执行。

检测 Skill 中的历史 `line_spectrum_metrics.py` 含重新检测和不同真值假设，不是本 Skill 执行器，不得在“只评价”任务中直接调用。
