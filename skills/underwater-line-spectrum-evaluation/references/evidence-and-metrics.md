# 证据与指标规则

状态：评价规范 0.1，评价运行时 1.0.0。以下定义是 V1 内置指标的证据和计算边界；不代表每次都要计算全部指标。执行方法见 [评价执行器 V1](runtime-v1.md)。

## 1. 明确评价对象与零假设

先问“什么算应当检出的线谱”，再问是否有足够证据判别。通用窄带线谱存在性、指定频率的可检出性、指定目标归属是不同问题。其他船、设备或平台的真线谱，不因不是目标船就自动成为通用检测的虚警。真值只能支持其标注的对象与粒度。

分别记录真值/背景的来源、版本或摘要、获取方式、时间频率覆盖、可信条件、未知/争议区域和标注粒度（待检单元、帧内谱峰、事件等）。空真值表可能表示“未标注”，也可能表示“经确认范围内没有线谱”，必须有明确语义，不能根据空表猜测。

训练单元的局部背景估计只是检测器统计量，不是已核验的背景真值；用户批准某个背景假设也不是事实认证。

## 2. 证据决定可计算性

| 证据 | 可支持的工作 | 不能直接支持 |
|---|---|---|
| 范围内完整标注，正负/忽略区语义明确 | 在相同覆盖与匹配规则下统计 TP、FP、FN、检出与误差 | 向未标注范围或新海况外推性能 |
| 部分正样本或少量人工核验 | 已标注子集的匹配率、已核验候选的正确性描述 | 把所有未匹配候选判成 FP；把子集匹配率当总体检出率 |
| 有依据的纯背景范围 | 该背景、处理链和计数层级下的误报观测 | 未标注混合数据的实际误报，目标检出率 |
| 无真值的数值结果 | 候选总数、每帧数量、分布、已提供的背景对比和门限余量 | 实际 FP/FN、检出率、精确率、真值频率 RMSE |
| 仿真或带已知注入信号的对照 | 已声明模型/注入条件下的性能 | 把模型结果直接称为海试性能；原实测背景中的未知候选当 FP |
| 仅图片或文字 | 可见现象、标注/图轴问题、有限半定量描述 | 精确可靠性指标、完整覆盖统计、无证据的目标身份 |

部分标注可在被声明为完整的局部时频区域内形成完整评价，其他区域仍未知。只核验检测候选的正确性不能得出漏检率；抽查比例未经抽样设计不能外推总体精确率。

先列每项指标缺什么证据，再由用户决定补充、改变评价范围、接受明确限制或跳过。不强制无真值用户补标注，也不因此停止有意义的描述分析。

## 3. 无真值时的第一版描述指标

逐时间窗任务可选择：

- 候选总数、每个有效完成窗口的候选数、平均候选数、有候选窗口占比。
- 在明确时间/频率分组下的数量分布；分组边界需要明确，不自动选图箱宽。
- 已有候选判据中的峰值、背景统计量、门限、超门限余量等；按原算法定义解释。
- 已有波束/谱图的对应关系与同源结果差异，不形成自动同目标归并。

设 F 为选定范围内成功完成且可评价的窗口集合，K_j 为第 j 窗口的最终候选数：

- 平均候选数 = sum(K_j) / |F|。
- 有候选窗口占比 = count(K_j > 0) / |F|。

必须包含成功但 K_j=0 的窗口；未运行、失败、缺失、无有效输入的窗口不填 0，另报请求窗口数、完成数和排除原因。若候选输出被截断、只交付部分候选或只含“有检出”的行，先核对完整性，不能将其视作完整统计。|F|=0 时结果未定义。不同算法有效覆盖不同，报告差异，公平对比需明确共同范围。

整段平均谱是另一个检测任务：可报告这一张谱的候选数，不能把构成平均谱的 STFT 帧数当检测试验次数。分析支持区间不等于候选事件持续时间；不从帧计数偷偷建立轨迹或持续时间指标。

对已明确是同尺度正值功率/PSD 的峰值 P、门限 T，可定义门限余量 10 log10(P/T)；背景对比可按原统计量 Z 定义 10 log10(P/Z)。需说明 Z 是 CA 均值、OS 次序统计量或其他量，不能统称物理 SNR、真值或正确概率。零/负值、未知尺度或缺失中间量先报告，不加任意 epsilon 或重算背景来补齐。

## 4. 有证据时再计算误报与检出

评价前确认频带、有效时间、标签覆盖、频率/时间容差、一对一匹配方式、平局处理及重复候选规则。没有统一默认门宽，也不按“能得到最好分数”的方式匹配。

在同一完整标注且可评价范围内，以明确的一对一匹配计 TP、未匹配真值计 FN；FP 只在正负与重复规则足以判定时计数。匹配结果另存，不删除或修改原候选。重复候选是否计 FP 要明确；不能为了精确率好看而临时去重。

- recall = TP / (TP + FN)；说明是谱线、帧内谱峰或其他哪一种检出率的经验估计，不把同源重叠帧当独立重复试验。
- precision = TP / (TP + FP)；该分母须包含被评价规则定义的全部预测阳性。
- F1 = 2TP / (2TP + FP + FN)；按自身分母判断是否定义，不强行从未定义的 precision 反推。
- 频率偏差、MAE、RMSE 只使用已匹配项，同时报告匹配数与漏检数。无匹配时不可算；FFT 网格间隔不等于实际分辨能力，不能虚构亚频点精度。
- 全背景范围可有 FP，但没有正样本时 recall 未定义，不能记为 0 或 100%。

每个指标独立判断定义域。某项分母为零不意味着所有指标均不可算，也不能沿用软件库的零值填充规则而不说明。

## 5. “平均误报数量”与“误报概率”分开

设 V_j 为在证据足够的第 j 个评价单位内可判定的误报数。必须明确计数层级是“CFAR 单元过门限”还是“峰筛选后的候选”，两者不得混用。

| 指标 | 定义/分母 | 证据要求 |
|---|---|---|
| 每帧平均误报数 | sum(V_j) / 可评价帧数 | 完整标签覆盖或可信背景；包括零误报有效帧；注明全背景或混合场景 |
| 单位时间候选误报数 | FP / 有效观测小时 | 候选计数及已声明去重规则；明确有效时间，不能用首末候选时间推断 |
| 每合格 H0 单元误过门限比例 | H0 单元过门限数 / 全部合格 H0 待检单元数 | 单元级零假设与完整试验掩码、判决，或足够核验的同口径计数 |
| 背景帧误报事件比例 | 有至少一次误报的背景帧数 / 合格背景帧数 | 完整背景帧证据与明确单元级/候选级事件 |
| 背景整段误报事件比例 | 有至少一次误报的背景段数 / 合格背景段数 | 明确定义、可比的多段背景重复观测及分组边界 |
| 检出结果中的误报占比 | FP / (TP + FP) | 足够的候选真值；不是按所有 H0 试验定义的 Pfa |

时间窗重叠时，不把各窗长度之和当作唯一物理观测时长；需要统计时长时使用已声明有效覆盖规则并处理重叠/缺口。逐帧重复报告同一线谱不等于多个独立报警事件；改成事件计数需要另行明确关联规则，不在本版自动跟踪。

只含最终候选的表通常不足以恢复单元级虚警概率。没有真值的混合实测记录，即使算法声称 CFAR，也不能提供实际平均误报数或实际误报概率；此时报告平均候选数，并另列名义目标及其适用假设。

按帧/整段控制哪个范围、控制事件概率还是期望误报数，仍是待确认的检测设计选择。评价可以解释并分别衡量已选择的量，不替检测模块决定控制口径。

## 6. 标定、验证与不确定性

门限模型、目标值和系数拟合属于检测配置；评价负责核对它们的来源与独立验证证据，不在评价途中调到“通过”。使用过的数据分区、选择过的参数与是否独立留出必须报告。

理论概率依赖模型，标定观测依赖标定样本；二者不能充当未知海试背景下的实测性能。记录窗/谱平均、有效单元、CA/OS 与波束等实际链路差异。无可信背景时，可以建议人工复核、可信背景对照或模型/注入实验，但每次另行明确选择与授权。

经验零误报只表示本次观测未见误报。报告有效试验数量、覆盖与依赖关系；置信区间或罕见事件保证需要额外明确方法与假设，不自动用独立二项分布处理重叠帧、相关频点或同源波束。仅一段记录的单次事件结果不能证明整段概率达标。可报告描述性比例，不能未经设计声称可靠概率保证。

## 7. 比较与结论

明确比较的是检测器（例如同输入 CA/OS）还是上游波束处理（例如 CBF/MVDR 后的同一检测规则）；混合改变两者时只能报告整条链路差异，不归因于单一算法。核对数据、真值覆盖、窗/谱参数、频带、门限路线、统计层级、匹配规则与调参数据。不可比项分列；不能用候选更多、图更亮或同源一致直接宣布算法更好。

没有效果指标所需证据或验收要求时，效果结论为证据不足，不造通过/不通过。已有依据可支持某个格式或覆盖检查通过，但不能升级为整体算法工程通过。论文结论也只覆盖实际验证场景；不自动产生综合排名或加权总分。

本规范采用本项目的保守证据边界。基础定义参考 [scikit-learn 混淆矩阵文档](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.confusion_matrix.html)：分类评价需要真实类别与预测结果。CFAR 理论系数的模型限制可参见 [MathWorks CFARDetector 文档](https://www.mathworks.com/help/phased/ref/phased.cfardetector-system-object.html)，其中自动系数依赖规定的噪声与检测链假设；这不是对本项目海试条件的证明。
