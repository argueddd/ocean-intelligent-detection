# Underwater Line Spectrum Detection

检测负责“按什么规则找出候选”；独立评价 Skill 负责“这些结果表现怎样、证据是否充分”。按用户语言报告。数据事实和物理元数据不得猜测；可逆处理参数优先由输入事实、任务目标和本 Skill 规则推导，只有核心计算仍存在无法裁决的歧义时才询问。

## Harness 执行策略

- 用户明确要求对指定数据执行检测时，该请求同时授权完成任务所需的可逆参数选择、review/confirm/run 和必要结果保存。使用用户的实际请求作为执行证据，不另行逐项索要确认，也不伪称用户给出了未提供的数值。
- 参数按“可靠上游事实 → 确定性推导 → 数据驱动设置 → 本 Skill 保守基线”确定。`parameter_evidence` 中，上游值记为 `upstream`，用户明确选择记为 `user_choice`，Harness 推导或基线选择记为 `assumption` 并写清规则和依据。
- CA 与 OS、逐窗与平均谱、理论与标定路线只选与任务和证据相符的一条；不为了展示能力全部运行。缺少匹配 H0 标定数据时，逐窗初筛优先采用理论路线并明确名义模型限制；平均谱检测若无匹配标定则报告该路线受阻，不套用单指数门限。
- 输出写入 `.run/` 下新的任务目录；默认保存候选、完整 ledger、实际配置和结果清单。只有用户需要查看或后续任务确实依赖时才生成大矩阵、谱图、HTML 或跟踪交接，避免无意义计算。
- 必须提问时，先完成不依赖答案的检查，并把信号身份、物理元数据冲突、任务目标歧义等全部阻断项一次列出，附推荐选择和影响。单位、真值、评价阈值缺失通常降低解释或评价等级，不阻断原始单位下的检测。

## 当前能力与边界

第一版运行实现 1.0.0 已接通：输入核对 → 参数/来源门禁 → 单边 PSD → CA/OS-CFAR → 候选及覆盖账本 → 按需交付 → 波束协作。五类公共契约仍是 0.1.0；主/旁路交接、基础预检及理论内核保持各自版本与权限。

| 内容 | 已实现范围 |
|---|---|
| 输入 | 完整波束/旁路交接包 → 明确 signal_id 的单通道 SignalInput；保留原始来源、掩码、单位、时间和列映射 |
| 参数与运行门禁 | 闭合参数 Schema、固定算法登记、实现摘要、强制上游适配、科学/资源/产物核对、独立执行确认、来源复核 |
| 谱计算 | 完整有效帧单边 PSD；周期 Hann/矩形窗；显式去均值；有效帧算术平均谱 |
| 检测 | CA/OS 显式选择；帧/段 q/M 理论路线或匹配 H0 最大值标定；双侧完整参考、候选归并/并列/可选宽度与间距过滤 |
| 交付 | 候选与最小判据/覆盖、按需矩阵/账本/谱图/时频图/HTML；计算、查看、保存分开；新结果独占另存 |
| 下游交接 | 已完成逐窗任务的完整候选表、完整帧/单元账本及原生时频网格可生成只读跟踪输入清单；不产生轨迹、同源或目标身份 |
| 波束协作 | 限定记录内正反来源索引；已有检测与波束谱/空间背景联合查看；经双方门禁确认后的一次性检测/波束补算及新关联记录 |

代码与合成链路回归不等于 S59 实测效果、真实虚警/检出性能、物理阵列正确或工程验收。效果评价由已接入的独立评价 Skill 按其自身输入契约和证据等级执行，检测完成本身不等于评价通过。

## 必须延续的规则

- 可靠上游事实直接继承并留出处；用户选择、Harness 推导、已接受假设、未知、不适用分开。接受未知不把它改成事实已知。示例和历史 S59 参数不能冒充本次数据事实。
- 显式记录信号、区间、频带、算法、任务与门限路线。多输入身份或物理语义确实无法裁决时一次询问；不静默选第一条/全部/最强束，不默认把 CA/OS 或逐窗/平均谱两种全算，不失败后自动切换。
- 原数据和上游结果只读，不静默修复、转置、拼接缺口、滤波、重采样、归一化或改标定。谱计算中的分帧/去均值/加窗属于明确申报并确认的处理步骤。
- 帧/段概率按本次 task 的单信号、单检测算法分别控制，不宣称多束/多算法/多 task 的同值联合保证。平均误报数量归评价。平均谱不套用单次指数理论系数。
- 没有合格帧/可检验单元，与“成功且零候选”分开；全部分析行（含零候选）保留可核验覆盖。未检验单元不当阴性，不加 epsilon 消除零背景。
- 交接完成、参数就绪、执行确认、计算完成、结果保存、质量通过是不同状态。旧 preflight 的确认只记录预检，不授权新执行器；真实用户表述不得伪造。
- compute/view/save 分开确认。最小追溯信息随持久结果交付，大矩阵和图集仅按请求生成/保存；临时结果不承诺永久可读。缺少现有产物时报告，不借“查看”偷偷补算。
- 候选不是目标，分析窗不是事件持续时间，组宽不是物理线宽，P/Z 不是物理 SNR 或目标概率。未知单位不标声压级；同源 CBF/MVDR 不是真值或独立证据。当前 `AssociationRecord` 只表示来源/结果关系，不产生 `track_id`、`source_id`、`target_id` 或 `same_target` 结论。
- 不做自动目标选择、方向/频率轨迹跟踪、谐波归并、DEMON 执行、实时处理、跨阵相干合并或自动反馈。补算一次一确认，不扩展成持续搜索。

## 路由与必读参考

先区分当前任务，不把输入交接、解释或只读审查扩展为实验。

- **职责/公共接口设计**：读 [框架范围](references/framework-v01.md)，再按需完整读 [输入](references/framework-input.md)、[算法](references/framework-algorithm.md)、[请求](references/framework-request.md)、[结果](references/framework-result.md)、[关联](references/framework-association.md)。公共接口保持算法无关，不为了填格式代选具体算法。
- **接入已有时域**：完整读 [输入适配器](references/input-adapter.md) 与 [波束交接](references/beamformed-input.md)。主波束 execute 0.4 的已保存时域及已核对旁路信号可以接入；裸 NPY、只有谱图、未知轴不自动解释。旁路另读同级波束 Skill 的 bypass-handoff 参考。只做交接时不索要检测门限或执行检测。
- **方法/数值执行**：完整读 [CFAR 方法](references/cfar-design.md)、[概率与门限](references/cfar-threshold-design.md)、[运行入口](references/runtime-v1.md)。维护系数内核时另读 [理论数值边界](references/cfar-theory-core.md)。使用算法说明导出的真实字段，不捏造实现摘要。
- **离线门限标定**：在上述方法参考基础上，完整读 [标定入口](references/calibration-v1.md)。H0 来源、独立试验、模型/处理匹配、置信度与样本规模先明确；无标签录音不自动当纯背景。
- **查看/保存/波束补算**：完整读 [结果规则](references/framework-result.md)、[关联规则](references/framework-association.md) 与 [协作执行入口](references/association-runtime-v1.md)。波束补算还须读取同级 underwater-beamforming 的入口及相应执行/产物规范，用其自身门禁，不复制波束算法或绕过时域方向选择。
- **向未来频率轨迹模块交接**：完整读 [跟踪交接](references/tracking-handoff.md)。只从用户明确指定的已完成逐窗任务生成包外只读证据清单，要求候选和账本均完整保存；不运行跟踪、不把来源索引解释成物理同源关系。
- **JSON/基础预检**：完整读 [结构检查](references/schema-validation.md) 或 [受限预检](references/preflight.md)。两者始终只读、can_execute=false，不做身份认证，不代替新 runtime 的门禁和确认。

`detection_runtime.py`、`cfar_calibration.py` 采用 review → confirm → run。用户本轮明确要求执行时，以该真实请求及会话引用生成对应 scope 的 receipt；review 通过后直接继续，不把技术门禁变成第二轮许可。来源/参数/实现/输出变化后重新 review，并仅在变化超出原请求授权或产生新的实质阻断时询问。依赖缺失时报告，不自动安装或改系统配置。

## 检测与评价的交接

已有结果的误报/漏检/Pd/频率误差、比较指标、证据充分性和验收转同级 [underwater-line-spectrum-evaluation](../underwater-line-spectrum-evaluation/SKILL.md)。完整读其入口及适用参考；依赖缺失时报告，不回退旧 metrics 代算。

- 检测输出实际候选、判据、参数、覆盖/排除与来源；评价只消费已有证据，不倒改检测结果或门限。评价建议也不授权新检测/波束计算。
- 无真值只能描述候选和可观测现象，未标注不是负样本，候选数不是误报数。真线谱与目标归属不同。
- CFAR 门限控制、公式和系数标定仍归检测。独立验证只支持所声明 H0/流程；不据此声称真实录音质量或工程通过。
- 根据所选评价指标确认所需细粒度证据，缺失则报告不可算。最小覆盖账本与可选单元矩阵的区别见 [评价交接设计](../underwater-line-spectrum-evaluation/references/evaluation-handoff.md)。不自动补算未保留的矩阵。

`line_spectrum_methods.py` 与 `line_spectrum_metrics.py` 不属于本版执行器。旧 metrics 的 psd/lofar 会重新检测，旧 psd 无真值时还会把候选当误报，不得用作新评价执行器，也不得仅删几个输出字段掩盖语义差异。

交付时清楚说明本次实际做了什么、输入与已确认选择、未决项/限制、结果定位、验证范围。除用户明确要求，不运行实测、不自动打包/发送、不自动增加评价或目标判断。
