# CFAR 事件概率与门限 v1

2026-10-05。用户已确认理论均分预算与离线最大值标定、完整双侧参考、谱和候选规则；运行实现见 [执行入口](runtime-v1.md)。本页解释数学适用范围，不提供实测默认数值。

## 控制对象和范围

| 用户选择 | 对象 | 不代表 |
|---|---|---|
| frame | 声明 H0 下，该帧指定搜索带至少一个合格 CUT 超门限的概率目标 q | 不是单频点或整份数据的同值目标 |
| segment | 声明 H0 下，本 task 所有纳入检验的时频单元至少一次超门限的概率目标 q | 不是每帧可重复使用整段预算 |
| 平均误报数量 | 独立评价中的计数目标，不是本版门限开关 | 不是事件概率，也不是每帧最多几个 |

最终候选只从过门限单元中保留，归并和筛选不会增加至少一次事件，因此原始事件上界也约束最终候选事件，但不等于二者概率相同。通过门限不是“目标为真”的概率。

每条输入信号 × 每个检测算法单独声明范围；跨束、跨算法及不同 task 不宣称联合同值控制。相同信号同时选择逐窗/平均谱时，逐次明确接受本版的独立 task 范围，否则阻断，不暗中拆分共享预算。

平均谱是把有效帧平均成一张谱；segment 控制是将选定检测范围纳入一个事件，两者不是同一个开关。平均谱仅接受 segment + 匹配标定；逐窗任务可选 frame 或 segment。

## 几何检验数和联合界

先由已核对的完整帧支持、FFT 网格、搜索带和完整双侧参考规则确定合格 CUT 集。帧级 M 为该帧几何合格 CUT 数；逐窗整段 M 为合格 CUT 数乘有效完整帧数。平均谱只有一行，但本版不走单指数理论。

理论 p_cell=q/M。M 在计算 PSD 与看候选之前确定；零/非有限背景造成的未检验单元不回收预算，不按峰数、高值或人为“有效独立频点数”减少 M。空帧/空检验集不是零误报试验。

若各项 H0 单元概率确实不超过分配值，则“至少一项过门限”的事件概率不超过各 p_i 之和，均分时不超过 q。联合界不要求不同检验之间独立，但每项 CFAR 单元模型仍须成立；不能用“帧/频点相关没关系”掩盖错误单元模型。[NIST Bonferroni 不等式](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)

本版不隐式改用 Sidak、不进行数据依赖预算优化。q/M 偏保守，名义上界不是实测 Pfa。数值根的残差和 binary64 限制随配置保存，不作严格有向舍入的形式化概率证明。

## 参考与保护区

每侧参考数 R>=1、每侧保护数 G>=0 均为显式整数，N=2R。对原 FFT 索引 j：

```text
左参考 j-G-R ... j-G-1
左保护 j-G ... j-1
CUT j
右保护 j+1 ... j+G
右参考 j+G+1 ... j+G+R
```

DC 及偶数 FFT 的 Nyquist 既不作 CUT 也不作参考。奇数 FFT 最末正频不是 Nyquist，但仍须完整参考。参考必须全部位于显式 reference_band_hz 内，且不越出已知上游频带；search_band_hz 不隐式扩大参考支持。Hz 需求若需换算 R/G，先展示转换后的整数与实际宽度供确认。

参考不足按明确 skip_and_report/stop 处理；不缩窗、补零、绕到另一侧或改变 N/k。谱/有效性规则和候选筛选见 [方法设计](cfar-design.md)。

## 理论系数

假设 CUT 与 N 个参考功率独立同分布为同均值指数变量，参考区同质且无干扰线谱。不是对任意 STFT/Welch/波束输出都成立的公式。

CA 使用均值，不是总和：

```text
Z = mean(X_1 ... X_N)
Pfa(alpha) = (1+alpha/N)^(-N)
alpha = N*expm1(-log(p_cell)/N)
```

参见 [MathWorks CFAR 教程](https://www.mathworks.com/help/phased/ug/constant-false-alarm-rate-cfar-detection.html)。参考区有强线谱/斜率或非同质背景时，不能由该式保证实测概率。

OS 使用升序第 k 值，1<=k<=N：

```text
Z = X_(k)
Pfa(alpha) = product((N-i)/(N-i+alpha), i=0,...,k-1)
```

在对数域求唯一正根：sum(-log1p(alpha/(N-i)))=log(p_cell)。这与 [Rohling 第36式](https://nato-us.org/sensors2005/papers/rohling.pdf) 的顺序统计量形式一致，不借用其雷达参数/效果作为水声证据。

实现与容差见 [cfar_theory 0.1.0](cfar-theory-core.md)，包括正反公式、残差、支持边界和失败，不自动回退 CA/经验门限。理论内核自身不分配预算；新 runtime 才根据明确事件范围算 q/M。

Hann、零填充相关、MVDR 自适应权重等会影响模型。程序要求显式 nominal_approximation 才允许这类输入走理论路线；这不是模型认证。矩形窗也不自动证明噪声白、同质或独立。

平均谱不是单次指数观测；重叠平均的独立自由度不能猜测。第一版不增加 Gamma/F/经验自由度理论分支，平均任务走流程匹配标定。参见 [SciPy Welch](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html) 的分段平均定义。

## 离线标定和独立验证

本版直接标定完整帧/段的最大 R_j=P_j/Z_j，不先拟合单频点概率再改名为帧/段概率。固定同一 PSD、CA/OS、参考区、有效支持与事件范围；每个明确 H0 trial 提供一个完整事件最大值。跨算法/波束不混合最大值。

用单独 calibration 集选系数，独立 validation 集核验；帧控制试验不把同一段的重叠帧充当独立重复，整段控制匹配完整段的相对帧/缺口结构。H0 来源、独立依据、处理等价、置信度、最少试验数与预算必须明确。

目前支持保守秩分位数、单侧 Clopper–Pearson 上界不大于 q 的验证判据，详见 [标定入口及精确字段](calibration-v1.md)。没有自动噪声模型、自动安静片段选择、尾部外推或验证集调阈值。样本不足或验证失败的记录不得供检测使用。

模型/配置/频带/平均结构不匹配时先报告或询问，不重算上游、不重标定、不换理论。系数记录保存真实来源与校准/验证划分；接收 hash 只证明内容一致，不认证 H0 物理真实性。

## 异常、计数与证据边界

P、Z、T 用线性 PSD；dB 只显示。严格 P>T，不用大于等于。Z<=0/非有限时按明确策略报告未检验；T 溢出阻断。不加 epsilon、不把未检验单元当阴性。OS 的 P/Z 不是物理 SNR，任何比值都不是目标置信度。

最小结果保留全部分析行（含零候选）、几何合格频点、异常排除和实际覆盖；完整矩阵/全组剔除细节按需保存。真实候选误报/漏检/精度统计属于独立评价。没有可信 H0 或真值，不能把候选数量叫平均误报数量。

纯背景概率约束也不自动证明含真线谱、参考污染、传播变化等混合场景中的强控制。无标签实际录音不能单独证明整段风险 q 已达到。现有合成回归只验证实现与规则，不宣称海试效果或工程验收。
