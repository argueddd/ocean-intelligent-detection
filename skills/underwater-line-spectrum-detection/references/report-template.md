# 方法说明与评价报告入口

不强制十项完整报告或未请求的图集。方法设计说明可按本次问题包括：目标与已知输入、明确选择、方案与适用假设、参数/问题清单、实现状态和经确认后的下一步。设计建议不是本次计算授权。

已有结果的评价报告由 [线谱评价 Skill](../../underwater-line-spectrum-evaluation/SKILL.md) 负责。根据证据选择有真值性能评价或无真值结果分析，并按用户选择输出：

- 实际评价对象、范围与证据状态；
- 所选指标或观察，数值附定义、单位、分母与限制；
- 不可算的项目及原因；
- 波束/检测结果引用，可支持与不能支持的结论；
- 如有需要，另行建议的补证据或计算请求，不自动实施。

无真值报告不能套用空的 Pd/误报/RMSE 表再以 0 补齐。无验收条件不能自动形成工程通过；运行/格式检查与效果评价结论分开。不把候选对背景的对比一律称为物理 SNR，不自动补轨迹、谐波或 DEMON 分析。
