# 质量检查规则

指标绑定原始通道位置与半开样本区间。逐块覆盖整个请求范围，块边界接续零值/恒值游程。失败不能报告完整覆盖。

逐通道算总数、有限值、NaN、正负 Inf、零值计数/比例、均值、总体标准差、RMS、绝对峰值、极值及最长零值/恒值片段位置和长度。NaN/Inf 不参与有限统计，分母单独记录，不代表删除原数据。无有限值时统计为 null。

统计累积采用内部尺度稳定计算，最终恢复原始数值单位；这不修改输入或执行幅值归一化预处理。最终非零统计量若无法用 float64 表示，明确报告 numeric_range，不把下溢的零作为有效结果。

非有限值记录连续区间总数及前 100 个精确半开样本区间；跨块接续，超过 100 时明确标记列表已截断，计数仍覆盖完整请求范围。不能把截断列表当作全部异常位置。

零值、恒值和幅值差异是观测，不直接认定坏道或增益故障。uint8 PCM 保留原编码，直流解释须考虑编码。不给出无来源的坏道分数。

当前脚本尚未实现参考满量程削波、采集时间连续性、独立参考同步、极性/串扰/幅相标定故障判定。这些子项标为 not_implemented，而不是只标缺参数；后续既需要相应参考数据，也需要实现检查。已实现的坐标一致性检查缺坐标时才标 blocked。

相关性只在声明片段、共同有限且非恒值通道上算，不插值或拼接。相干估计至少两个完整分段，否则跳过说明。

几何只核对完整映射、坐标数、有限性和重复坐标。几何一致不证明同步/标定。工程验收需用户规则，本版输出证据与限制。

运行结束核对源文件大小和 mtime；变化或消失使本次结果无效，保留诊断产物并明确失败。元数据未变化不等于内容哈希验证，也不构成对并发写入源的完整快照保证。
