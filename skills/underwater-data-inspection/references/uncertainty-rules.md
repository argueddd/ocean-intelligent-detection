# 不确定信息处理规则

每项关键事实记录 value、state、sources；state 为 confirmed/missing/ambiguous/conflict。推导事实保留计算依据。未知用 null，不能用 0、空字符串或经验值伪装成观测事实。格式规范、文件头、显式维度标签、唯一结构候选或可信配置能够唯一确定的事实可以直接记为 confirmed，并注明来源；不需要用户重复确认。

格式头只能确认格式明确规定的字段。MAT/HDF5 变量名只是线索；含义需由用户/格式说明确认。配置代表明确选择，保存配置来源。智能体不能把猜测写成“用户确认”。

| 情况 | 可以继续 | 暂停与询问 |
|---|---|---|
| 多字段或语义不明 | 列字段、形状、类型；唯一候选可直接使用 | 多个实质候选都合理时，波形位于哪个字段 |
| 轴不明确 | 文件探查；格式或标签唯一确定时直接使用 | 多个轴解释都合理时，哪一维是样本 |
| 采样率缺失/冲突 | 轴确认后的样本统计 | 秒/Hz、PSD、时频和相干分析 |
| 单位/标定缺失 | 原始数值及相对分析 | 物理声压、校准声级 |
| 映射/几何缺失 | 按原始列位置检查 | 阵元归属和方位结论 |
| ADC 满量程未知 | 极值和恒值片段 | 确认削波率/饱和故障 |
| 无采集时间参考 | 检查存储数组 | 实际丢帧、重复帧和同步 |

提问前先完成不依赖答案的探查和检查。把本轮所有当前阻断项合并在一个“需要你确认”清单中，每项包含对象、实际观测、推荐选择、备选及受影响步骤；允许用户回复“按推荐执行”。例如数组 `/recordings` 存在两个同等合理的轴解释时，列出两个形状解释并推荐有标签/配置证据的一项。缺元数据不等于故障；某步受阻不能丢弃已完成结果。没有证据优势的候选解释不能冒充事实代入计算。

采样率、单位、轴语义、阵列位置是事实，不设经验默认值。窗长、重叠、块大小、预算、诊断图和代表性覆盖是设置，默认由智能体选择并记录。选前段或部分通道只是覆盖选择，不表示代表性样本。

sample_rate_resolution 只用于已展示的冲突，要求 use 和非空 reason，并保留双方。智能体不得替用户编造理由。不得捕获错误后轮流尝试字段/转置直到“能跑”。

允许已确认的轴转置、单通道二维视图和切片，均记录。分析阶段临时浮点转换单独记录，不改源数据。超过 2^53 的大整数暂停 float64 数值分析以免丢失精度。

禁止静默重采样、插值、删异常、换算、均衡、滤波、删道或重排。谱估计的加窗与每段减均值必须记录，不能覆盖原信号。
