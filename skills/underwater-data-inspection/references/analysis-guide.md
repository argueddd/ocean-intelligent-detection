# 基础分析规则

字段、轴与 fs 确认后才做秒/Hz 分析。单位未知用原始数值单位，不输出校准声级。大整数超过 2^53 暂停浮点分析。

默认最多分析请求起点后 262144 样本、前 4 路，这是预算而非代表性抽样。事前说明并记录，用户范围优先。完整性检查仍覆盖全请求。

Welch PSD：Hann、density、单边、每段减均值、默认 50% 重叠、nfft=nperseg。nperseg 默认 min(4096,分析样本数)，至少 8。记录频率网格间距，不等同实际可分辨能力。

窗长与帧间隔只描述本次估计设置。未做相应验证时，不把窗长当作可探测瞬态的绝对最短时长，也不由频率网格承诺两个邻近线谱必然可分辨。

时频图用相同设置，不补尾部。记录读取覆盖、完整窗口覆盖、尾部未用样本；时间轴为窗中心。

全频 PSD 功率按 sum(PSD)*df 算，含加窗/去均值效应，不要求任意数据等于原始含直流 RMS 平方。band_hz 只截取频点，不代表带通。

输出数值 NPZ、波形、PSD、时频图。dB 参考一个原始数值单位平方/Hz，明确标注。显示下限不改线性矩阵；波形抽点记录方法，不从缩略图断言无尖峰。

含 NaN/Inf 的分析通道跳过频谱/配对并报告，不拼接有效样本。窄带峰是观察，不认定目标。无参考不算严格 SNR/SINR、检测率、虚警率和定位误差。

## 结果与图表核对

默认以已有 result.json、CSV 和必要的 NPZ 数值为依据，核对范围、参数、频点与指标；不要为核对重新读取波形或重复运行 Welch/时频分析。解释已有结果只读取与问题有关的字段。

用户要求读图、存在必须观察图面才能回答的问题，或数值无法解释可见异常时，才调用独立视觉工具（本 Harness 为 vision_inspect）。每张相关图调用一次，并复用已有视觉结果；返回 partial 仅在缺失内容妨碍当前结论时，对同图用更窄的问题补问一次，仍不足则说明限制并交付。数值已足以回答时，不因 partial 继续补读或扩大分析。

视觉证据只支持可见结构及近似位置，精确频点和覆盖以数值产物为准。二者不一致时说明哪项观察未得到数值支持，不默认重跑原始分析。视觉不可用而任务仍要求图面结论时，明确该图尚未视觉复核；PNG 有效不等于图表内容已验证。普通数值任务不要求所有 PNG 都经视觉复核。
