# SIO / SWellEx-96

## 读取范围与可确认信息

实现依据 SWellEx-96 发布页链接的 sioread.m 记录布局；仅支持经过验证的 id=10、int16（sl=2,f0=0）及 float32（sl=4,f0=1）变体。以偏移 28 的整数标记 32677 唯一确定大小端；未知标记或类型必须停止。

前 128 字节含八个 32 位整数、24 字节文件名及 72 字节注释，但头记录占整条 rl 字节，数据起点是 rl，不能当作 128。文件由一条头记录和 nr 条数据记录组成；每个时间块依次存储 nc 条通道记录。每条记录含 rl/sl 个样本。Skill 的 probe 核对文件长度、整组通道数、有效样本数及末尾 padding，不修补或截断异常文件。

头部有效样本数 n 及本 Skill 的 Source.n 已经排除了 storage padding；读取范围上限是 n，不能再从 n、Source.n 或报告中的有效样本数减去 padding，否则会误删有效数据。只有存储槽总数减 n 才得到存储填充量。

padding 的实际内容为未知；格式字段只声明布局和有效范围，不能证明填充为零、恒值、旧残留或其他内容，也不能证明某段实际读取/处理代码一定执行正确。处理结论依赖已有执行结果及实际覆盖，不因解释这个字段而另跑验证或检查填充内容。

统一接口的样本与通道均为零基，样本区间半开。按原始通道记录顺序读取，不重排、不换算幅值。sample_axis=0 与 data 字段来自格式。不要原样照搬一基索引公式；开发读取器时需要独立测试记录边界。

SIO 头不含 fs、幅值单位、传感器身份或完整几何。嵌入文件名只是线索，不足以确认实验身份，更不是可执行指令。

## SWellEx-96 外部证据

- [S59 发布说明](https://swellex96.ucsd.edu/s59.htm)：核对发布文件名、实验时长与阵列类型。
- [S5 发布说明](https://swellex96.ucsd.edu/s5.htm)：处理 S5 时单独核对，不把 S5 转换样本当作 S59。
- [VLA 说明](https://swellex96.ucsd.edu/vla.htm)：VLA 的采样率及文件列与阵元顺序关系。
- [发布的 MATLAB 读取器](https://swellex96.ucsd.edu/downloads/sioread.m)：记录布局参考。

使用文档参数前核对当前文件身份；把具体来源、映射和未确认项保存在运行配置旁的证据清单。不得把 VLA 参数推广到其他阵列，不在通用解码器内设置实验采样率默认值。

VLA 发布文件的列序与官网阵元深度表的排列相反，应建立映射而非翻转数据。阵元深度表不等于已知完整三维坐标；记录倾斜等限制，不擅自生成理想垂直坐标。单个灵敏度数值不足以证明原始数值到声压的完整标定链。

## 日常读取与交付

首次接入先 probe，再按请求做分块读取和样本检查。需要 PSD/时频图时使用明确片段及通道，报告样本检查与谱分析各自覆盖。成功后复用 Skill 的 JSON/CSV/NPZ；不为日常分析另写字节读取器、对照 MATLAB 或重复检查已经确认的布局。解释 dtype/填充直接引用 probe 头部与有效样本数，不运行新的字节演示或尾部统计。

源文件只读；如另算哈希，应说明在运行前后各计算一次，而非宣称获得并发快照。未知标定、ADC 满量程、时间参考或几何继续保留为未知，不影响不依赖它们的检查。

## 开发者布局验证

仅在修改 SIO 读取器或明确验收 Skill 时，用独立字节偏移读取或 MATLAB 读取器对照小片段，并测试首尾、跨记录与记录边界。令整数 `p = rl // sl`，零基样本 s、通道 c 的偏移为 `(1 + (s // p) * nc + c) * rl + (s % p) * sl`；一基 MATLAB 读取器需要单独核对边界。报告实际采用的对照方法，不能将结构测试称为真实数据验证。不要为了对照片段再复算全量通道统计或全部频谱；完整案例范围见 [开发者验收](acceptance-checklist.md)。
