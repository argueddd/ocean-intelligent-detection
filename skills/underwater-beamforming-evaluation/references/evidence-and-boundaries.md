# 证据、可比性与结论边界

## 1. 评价对象

本 Skill 评价已有波束结果，不评价“重跑一次后可能变好的结果”。每个评价目标要保留算法、输入包、beam ID/方向网格、时频范围、尺度、轴顺序和摘要。不得把输出功率扫描误称为 Capon 理论谱，不得把显示归一化 dB 值当绝对功率。

## 2. 证据等级

| 证据 | 可支持 | 不可直接支持 |
|---|---|---|
| 图像 | 主瓣/旁瓣现象、轨迹可读性、图表问题 | 无坐标/色标保证的精确数值 |
| 无真值数组 | 峰位置、波束宽度、旁瓣、假峰、稳定性 | 定位准确性、真目标检出率、实测虚警率 |
| 可比基线 | 同定义下的增益、抑制和相对改善 | 不可比处理链之间的单因素归因 |
| 覆盖明确的真值 | 覆盖内 DOA 误差、检出/漏检/虚警、真值轨迹连续性 | 未标注海况、时段或新阵型的外推 |
| 独立数据 + 已批准阈值 | 指定范围的工程验收 | 范围外部署保证 |

预期方位、船舶 AIS、人工挑选的明显轨迹可作参考，但必须声明来源、时空对齐和覆盖；“看起来对”不自动升级为真值。

## 3. 可比性

算法比较至少核对：

- 同一源数据、样本/时段、通道和阵列几何；
- 同一方向网格和方向定义；
- 同一预处理、处理频带、窗、FFT/快拍和时间平均口径；
- 同一功率/幅度/dB 定义与线性归约；
- 同一真值覆盖、关联门宽、队列缺失处理和统计单元；
- 相同调参数据暴露和计算预算口径。

一旦同时改变波束算法、预处理和线谱检测器，只能评价整条链路差异，不能把改善归因于其中一项。

## 4. 匹配、跟踪与身份

DOA 序列与真值的单帧一对一关联属于评价计数；V1 采用“先最大匹配数，再最小化总角误差”，不使用可丢失可匹配目标的贪心最近对。这不建立跨帧目标身份。

无真值 BTR 的连续脊线和已给目标频带的时频连续性只是特征摘要。跨时间目标跟踪、多线谱谐波族关联、多波束声源归属和目标识别必须使用独立模块。

## 5. 验收与调优

工程判定只使用项目提供的阈值。`critical=true` 指标任一失败时不得被加权总分抵消；任一已设阈值指标缺测量值时，不得判为通过。缺少阈值时可给候选建议，但状态仍是“未验收”。

评价可将问题映射为下轮实验，例如“低快拍下 MVDR 假峰增加——扫描加载系数并以真值 RMSE + WNG + 目标保真作共同指标”。实际改参数和重跑属于调优/波束形成流程，需新的明确配置与授权。
