# SWellEx-96 S59 实测流程验证

本记录只证明评价 Skill 能只读消费已有实测波束产物并生成可审计结果包。它不是入射方位真值验证、目标检测验证或工程验收。

## 数据与范围

- 来源：SWellEx-96 S59 VLA 首60秒，21通道历史波束形成结果。
- 算法：CBF 和 MVDR；37个阵列角扫描方向，−90…90度，5度间隔。
- 分析产物：线性输出 PSD、带内 BTR 功率和时间平均扫描功率，40.283203125…449.70703125 Hz，163个有效分析帧。
- 上游结果文件 SHA-256：`5d42b092edfe29194e7e0736961928613e04a7741b12ea786a3521f5f3c9c2cb`。
- 评价请求执行时 SHA-256：`3be0070bcdcae2e05157d3ba5bf2fc849834ac852ea927045507077c9c57fccb`。

执行前核对了每个数组、坐标文件和上游 result.json 的 SHA-256。预检曾对一个错误路径正确阻断，更正后才执行。

## 已运行任务

对 CBF/MVDR 分别运行：

1. `spectrum`：扫描功率的峰位置、HPBW、主旁瓣比和假峰数；
2. `freq-bearing`：全分析频带各频点峰方位分布与线性功率融合谱；
3. `btr`：无真值最强连续脊线的连续性、跳变、背景对比和竞争峰描述。

共6个job全部完成，`EvaluationResult` 契约通过，包内 5 个清单文件摘要全部复核一致，`acceptance.status=not_requested`。
