# 水声波束形成

用中文协助用户建立可复查的 CBF 和 MVDR 流程。按来源事实、确定性推导和有记录的自主设置计算波束及谱；时域只保存任务实际需要的方向；线谱检测和目标身份判定属于下游任务。

## 自主决策规则

用户发出波束形成、扫描、比较或为下游生成波束的请求，即授权本 Skill 对可逆处理选择采用数据驱动设置或下述基线策略，不再逐项询问。契约中的确认记录应如实写明“用户任务请求 + Harness 自主决策规则”和实际推导依据，不伪称用户逐个给出数值。

- 事实优先级：当前请求明确值、输入契约/文件元数据、与当前源绑定的已保存配置、确定性推导。来源一致时直接使用；真正冲突且无法判定优先级时才询问。
- 用户已指定 CBF 或 MVDR 时保持该选择，不擅自追加另一算法。未指定算法的初次定位使用 CBF；明确要求算法比较时，在快拍和稳定性条件允许后执行 CBF+MVDR。只请求 MVDR 而条件不足时说明受阻，不用 CBF 冒充请求结果。
- 未知目标方向且任务要求搜索时使用网格扫描；网格范围由方向坐标的有效范围确定，步长由最高分析频率下的阵列名义角分辨率约四分之一推导，并限制为执行器支持的合理规模。已有目标方向时使用指定方向并可增加少量邻近方向检查稳健性。
- STFT 窗长优先由请求频率分辨率推导；未给分辨率时根据采样率、分析频带、数据长度和资源预算选基线窗，Hann 窗默认 50% 重叠，`nfft` 取不小于窗长的可执行值。相关事实未齐时只记录推导规则，不提前冻结窗长、加载量、协方差帧数或扫描步长等精确值；所有最终实际值写入配置和结果。
- CBF 初始阵元权重使用等权并做单位响应归一化。声速只有在没有测量值且用户接受探索性名义模型的项目授权下才可用 1500 m/s，并必须标为 nominal assumption；几何、通道映射和方向坐标不能凭空生成。
- 输出按任务链选择：定位/扫角保留空间谱或频率—方位结果；线谱下游保留所选波束时域与 PSD；普通预览保存必要诊断图。输出新目录、资源预算内的保留方向和绘图选项无需单独询问。
- 缺单位、标定或独立同步证据时，在原始单位下使用 `uncalibrated/none` 与 `assumed` 做探索性相对分析，限制物理声级和工程结论，不再询问是否接受；缺阵列几何/映射或方向坐标且核心计算依赖它们时才阻断。无实测声速时探索性任务直接采用 1500 m/s 并标为 nominal assumption。
- 不仅凭阵元数否定 CBF/MVDR。两阵元阵列空间自由度和分辨率有限，但仍可形成波束并运行 MVDR；应结合几何、快拍数、协方差秩/条件数和稳定性门禁判断，不能预先声称“没有实际增益”。
- 确需输入时，先完成结构核对和可执行分支，再把全部当前阻断项放入一次“需要你确认”清单，每项给出推荐处理及影响；允许回复“按推荐执行”。

## 必读规则

- 接收输入、编写适配器或设计输出时，完整阅读 [数据契约](references/data-contract.md)。
- 从读取检查模块接入时，完整阅读 [交接适配器](references/inspection-handoff.md)；先只读 review，再确认导出请求。prepare 不运行波束形成，生成的草稿不能直接当作执行授权。
- 单阵元/已有波束直接交接时，完整阅读 [旁路交接](references/bypass-handoff.md)。只传数据与信息，不执行检测；未知项处理须单独确认。
- 制定方案、填写参数或处理异常时，完整阅读 [参数确认与计算门禁](references/parameter-policy.md)。
- 调用检查器或编写 plan 时，完整阅读 [预检查接口 v0.2](references/preflight.md)。
- 调用、修改数值执行器或解释其结果时，完整阅读 [数值执行接口](references/numerical-execution.md) 和 [结果输出与展示及子集补图](references/output-products.md)。其中限定的字段与已实现轮廓是当前执行依据，不能把总体设计的全部字段称为已实现。
- 未知物理事实和无法裁决的冲突不能伪造。未选算法设置、输出选择和其他可逆处理项按上方自主规则解决并记录；用户的任务请求和本项目自主决策授权构成执行许可。
- 原始数据只读。不静默删道、补样本、转置、重采样、滤波、归一化、调整同步/标定、扩大频带或改输出精度。
- tests 中的数值和 MOCK 确认只服务于合成验证，不能作为实测的推荐默认值或真实授权。

## 输入分流

不能仅凭通道数推断身份。

| 输入身份 | 行为 |
|---|---|
| 多阵元原始时域信号 | 进入阵列参数确认和波束形成门禁 |
| 单阵元原始时域信号 | 不做阵列波束形成；按明确请求交下游，保留单阵元身份 |
| 已形成的一条或多条波束时域信号 | 不再当作阵元处理；逐波束保留身份及方向 |
| 身份、轴或通道含义不明 | 先用契约、格式和唯一结构证据判定；多个实质分支仍并存时合并询问 |
| PSD、空间谱、时频矩阵、图像、不支持编码 | 报告表示不匹配，不静默转换或取实部 |

旁路有独立受控文件交接入口，只接已完成的读取检查导出包，解析角色和任务所需 ID 后使用 bypass_handoff.py。已有波束方向、算法、频带或有效性未知时，在纯数据传递中按契约保留 unknown 并说明限制，不填 0°、CBF、全频带或全有效；只有下游核心计算依赖该元数据时才合并询问。交接本身不等于已执行频率分析或检测。

## 方向与算法

- 只实现 CBF、MVDR；按任务目标和上方基线策略选择一种或两种，并记录选择依据。
- 指定方向：specified，只计算任务需要的列表。网格扫描：grid，依据坐标约定、阵列分辨率和预算推导范围、间隔、端点与输出规模。
- 未说明方向且目标未知时采用受控网格扫描；方向坐标语义缺失且无法从几何契约确定时才询问。不把最强波束自动解释成真实目标，也不在本 Skill 内跟踪。
- MVDR 更新权重不等于改变方向。相移分箱使用窄带近似，按任务频带和窗参数记录适用范围；项目级自主授权允许探索性采用，但不能冒称精确宽带延时或真实方位已无歧义。
- 谱输出种类按任务目标自主选择，可单选或组合 PSD、时频图、频率—角度图、BTR、扫描功率；不生成与当前问题无关的整套产物。必要坐标、有效帧和来源信息始终保留。
- 计算方向与时域保留方向分开记录。按下游需要和资源预算选择保留子集：只评价空间响应时可以不保存时域，线谱下游保存实际选定的波束；不默认保存全部方向。主计算的所选谱覆盖全部计算方向，时域只写选定子集。
- 公开资料由智能体主动核查并记录来源；查不到就报告具体缺口，不反复要求用户提供不存在的文档。未核实映射仍不可静默采用。

## 命令入口

路径替换为实际绝对路径；数值入口需 NumPy/SciPy，预检查入口仅需标准库。

```bash
python3 <skill-dir>/scripts/preflight.py check <plan.json> --out <new-report-dir>
python3 <skill-dir>/scripts/preflight.py digests <plan.json>
python3 <skill-dir>/scripts/execute.py check <execution.json>
python3 <skill-dir>/scripts/execute.py digest <execution.json>
python3 <skill-dir>/scripts/execute.py run <execution.json>
python3 -B -W error::RuntimeWarning -m unittest discover -s <skill-dir>/tests
```

读取检查交接使用 scripts/inspection_handoff.py 的 review/check/digest/prepare 子命令，详情见交接文档和 [待确认导出模板](assets/inspection-handoff-request.json)。旁路使用 scripts/bypass_handoff.py 和 [旁路模板](assets/bypass-request.json)；子集补图使用 scripts/analyze_results.py 和 [子集补图模板](assets/subset-product-request.json)，详见各自参考文档。

preflight 支持历史 0.2 及新 0.4 plan；execution.json 使用 0.4 包装，包含 plan、numerics、analysis、独立 approval；经交接导入时另带 inspection_handoff 引用。可从 [不完整模板](assets/execution-request.json) 开始；null 留作待问事项，禁止为通过门禁擅自填值。

旧检查器的 can_execute 始终 false，报告不是执行令牌。新 check 的 can_attempt_execution 也只表示可尝试运行，run 仍验证真实编码、摘要、重建、条件数和磁盘。digest 不生成确认记录。内部 beamforming_core.py 不负责授权，不能绕开 execute.py 直接用于未确认实测。

## 工作顺序

以下为原始阵列主计算顺序；旁路按旁路文档，已有结果补图按输出文档，不索要无关原始阵列参数。

1. 核实输入身份、来源、轴、通道映射、样本范围和上游实际检查覆盖。
2. 确认算法、计算方向、时域保留方向、所需谱产物、物理模型、预处理、STFT、端点、MVDR 更新/加载、谱分析与显示规则和资源预算；汇总阻断项。
3. 展示完整方案和近似影响，记录真实用户决定。任何影响结果或范围的变化重新确认。
4. 完整门禁通过且原请求要求波束形成时直接执行；真实物理事实受阻的分支不在提问间隙运行，其他独立分支继续。
5. 核对 result.json、所选时域与请求的全方向谱/图及其摘要、坐标、beam ID、有效帧、单位、共用显示尺度；未选时域时不应有时域文件，未选谱产物不应有对应结果或图集链接。
6. 分别报告参数就绪、程序完成、物理/工程验证状态。部分写盘无完成清单不能交下游。

## 对接与边界

- 普通 NPY 输入不要求安装其他 Skill；使用交接适配器导出时，需要同级 underwater-data-inspection 读取器。其报告不自带数据角色、时间原点与处理历史，由明确导出请求补充，不能从通道数猜测，也不能给旧读取配置塞未知键。
- 上游默认窗口、通道预算或 completed 状态不等于本次参数已确认，也不证明连续性、同步或标定。
- SWellEx-96 首次实测前还需明确数据片段、阵列几何/近似、声速、方向和数值设置；不能把采样率当声速，不能自动选择能量最强方向为目标。
- 当前时域结果带保守边界掩码，保留全部样本不裁短；掩码不证明采集质量或窄带近似精度。
- 本模块职责止于时域数据及相关信息的交接；不选择、询问或代填下游检测窗参数/阈值，不将检测执行器开发列为波束模块的后续必做项。
- 下游以用户指定且实际保存的时域波形及 metadata 交接；纯谱/图任务没有时域交付，多波束不能重新标成原始阵元。使用 [线谱输入交接说明](references/line-spectrum-handoff.md)。原运行的 handoff_status=blocked 保留为历史状态；适配器另发 prepared 输入包，不代表检测执行或联调通过。
- 没有真值或目标/噪声参考时，不报告严格 SNR/SINR 增益、定位精度或目标身份。结构校验、合成数值测试和实测验收是三类不同证据。
