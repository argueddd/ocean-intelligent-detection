# S59 VLA 受限实测流程证据

本记录只说明已运行覆盖；不是新任务的参数默认值、真值或授权。水平阵仍须分别确认完整通道映射，不得继承 VLA 倒序规则或凭通道数匹配直接计算。

## 已完成范围

- 原文件：SWellEx-96 S59 的 J1341145.vla.21els.sio；原始有效形状 [5850000,21]，采样率1500Hz。
- 只取源 [0,90000)，即首60秒，全部21通道；余64分钟未做本次波束形成。
- 用户明确批准：名义垂直坐标，1500m/s 名义常声速，阵内同步假设，未知单位/标定和上游处理历史保留。它们不是已测量/验证的事实。
- CBF 等权与 MVDR 同时执行；阵列角度 −90…90°、5°间隔，共37个方向；正角指向上，不是唯一水平地理方位。
- 每通道整段去均值；40–450Hz 活动 STFT 频点；周期 Hann 2048点、步长512、nfft2048、零边界、对偶窗合成、带外/DC/Nyquist置零。
- MVDR 使用172个完整训练帧，单次固定权重；加载为0.01×trace(R)/21，条件数上限1e8，数值响应容差1e-8。离线训练包括未来样本，不是实时系统。
- 独立片段导出适配器只做数值无损 float32→float64，不预先去均值或换算单位；通用执行器仍不支持 SIO 直接输入。

## 实测发现的实现问题

- JSON 经 JavaScript Number 中转会丢失纳秒大整数精度；首次门禁因此正确阻断。使用精确整数序列化后复核通过，源文件未变。
- NumPy2.2.6/macOS Accelerate 在有限坐标矩阵乘法上产生错误除零/溢出警告，独立求和结果一致。首次计算在保存前停止；修订为数学等价、非BLAS显式求和，并以 RuntimeWarning-as-error 跑回归与实测。
- 未改变已确认的物理模型、算法参数、加载量、精度或数据范围。没有全局依赖升级或警告屏蔽。

技术来源：[NumPy 官方缺陷记录](https://github.com/numpy/numpy/issues/28687)、[官方修复说明](https://github.com/numpy/numpy/pull/29223)。
实验事实来源：[S59](https://swellex96.ucsd.edu/s59.htm)、[VLA 采样率与倒序映射](https://swellex96.ucsd.edu/vla.htm)。
